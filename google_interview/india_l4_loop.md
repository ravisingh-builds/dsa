# India L4 loop (Bengaluru / Hyderabad reports)

Not the US “Gemini code comprehension” pilot. Ask your recruiter if anything differs.

## Order

1. **GHA** (sometimes) — online culture / situational quiz, ~30–45 min. Fail can mean a cooldown. Be honest; don’t “study personality.”
2. **Recruiter** — ~15–30 min. Role, **location** (BLR / HYD / other), timeline, work auth, CTC band. Have a 2-minute story of your career. This is not “just scheduling.”
3. **One coding phone** — DSA, **~45 min**, Google Meet. See [coding_phone_45min.md](coding_phone_45min.md). A **second** phone only if the first is weak.
4. **“Onsite”** — in India often still **virtual**, spread over **several days**. Typical:
   - **3 × DSA**, 45 min each
   - **1 × Googliness**, 45 min
5. **Hiring committee** reads the packet (they were not in the room). If they want more signal: **one extra DSA**.
6. **Team match** (India site) → offer. Timeline often **weeks to a few months**. Reject → often **6–12 month** cooldown.

**Total coding interviews you should expect: about 4** (1 phone + 3 onsite), not 2.

## What they ask

- Coding = **DSA** (arrays, graphs, grids, intervals, …). Titles are often **hidden**. Same path: contract → correct method → code → dry run → edges → Big-O.
- **Dedicated system design is usually not in the India L4 packet.** Common report: 3 DSA + Googliness. Some recruiters even let you pick **coding-focused** because “design is not mandatory ≤ L4.”
- **Not a hard 0%:** you can still get **API / class design** (write a type with methods) or a **short “how would this scale?”** inside coding. A few loops (more often US / a specific team) add a **light** design round. **Ask the recruiter** what *your* four onsites are.
- Googliness: STAR stories — conflict, unclear requirements, helping someone, a miss you learned from. Don’t trash old teams.
- Interviewers may sit in **Hyderabad, Europe, etc.**, not only your city.
- **No AI** on standard coding. You often **cannot run** code in VIP.

## India vs “first 2 rounds only”

Wrong picture: two 45-min DSA rounds and you’re hired.  
India L4 picture: **pass one phone**, then **three more DSA** plus behavioral.
