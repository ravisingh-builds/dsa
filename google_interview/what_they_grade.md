# What they grade (L4, with AI in the world)

Google is hiring **you in the room**, not “I prompted until tests passed.”

## Coding (the L4 gate)

They write up:

1. Did you restate the **contract** (types + meaning)?
2. Did you start from a **correct** complete search?
3. Did you name **time / space** in terms of `n`?
4. Did you skip work only with a **proof**?
5. Did you **dry-run** and poke **edges**?

A silent perfect function is weak. “Brute is `O(n²)`; here’s why I reuse work” is what the committee can quote.

Standard coding: **AI off**. A **May 2026 US pilot** (Gemini + read a codebase) is **not** the India default. Ask if it appears.

## Language

You need **one** language you can type for 45 minutes without autocomplete. Python is enough. `range(n)` = start 0, **stop `n`**, step 1; last index is `n-1`.

## Design

- **L4 (typical India):** no **full** distributed-design interview. Don’t start month 1 on a design textbook. Still learn later: APIs, a class with two methods, “what if this list is huge?”
- **L4 (some packets):** light design or LLD-ish. Recruiter confirms.
- **L5:** one full system-design round. Not the first-loop target.

RPA *is* a system (queues, retries, volume). Practice **saying** that later — half a page on one Labcorp flow is enough to start.

## Behavioral (Googliness)

L4: initiative, collaboration, learning from failure, user/customer.  
Not “I completed tickets.” Write STAR stories over the months; don’t cram the night before.

## Honest bar for this background

Daily coding was rare. That is a **skill gap**, not a life sentence. Target is **L5**. Expect: same coding path as L4 **plus** weekly HLD **plus** leadership stories. A first loop may still land **L4**. Prep so coding and design can support senior; don’t skip DSA to “study L5.”
