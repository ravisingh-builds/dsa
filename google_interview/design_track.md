# HLD / LLD vs DSA — how we track

DSA uses **`dsa_families/`** + **Pattern 1–15** in `dsa_families/PROGRESS.md`.  
Design uses **two other roots**. They are **not** more DSA patterns.

| Root | Interview name | What a “row” is |
|------|----------------|-----------------|
| `dsa_families/` | Coding | **Pattern** = how you **walk** (range, two indexes, notebook, …) |
| `hld_topics/` | System design (L5 hour) | **Block** (cache, queue, …) or **sketch** (URL shortener) |
| `low_level_design_topics/` | Class / API | **Problem** = one type you **code** (min stack, LRU) |

**Track:** each root has its own `PROGRESS.md` (same 🔒 🟡 ⬜).  
**Cadence:** DSA most days. HLD **45 min / week**. LLD month 3+ unless a recruiter says class/API.

Details: [hld_topics/PROGRESS.md](../hld_topics/PROGRESS.md), [low_level_design_topics/PROGRESS.md](../low_level_design_topics/PROGRESS.md).
